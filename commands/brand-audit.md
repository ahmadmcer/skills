description: Audit an existing digital brand identity and design system
---

$ARGUMENTS

Load the `branding-process` skill and conduct a read-only brand audit of the project or target interface.

1. Inspect the codebase styling, UI components, copywriting, logos, and color tokens.
2. Review the brand against the 4 Dimensions of Brand Heuristic Inspection (Strategy clarity, Verbal resonance, Visual coherence, and Accessibility/Token discipline).
3. Screen for the "Sea of Sameness" and category clichés.
4. Return a structured audit report with findings ranked by severity (P0 Critical, P1 Major, P2 Minor, P3 Cosmetic) with exact file locations, evidence, and concrete remediation steps.
