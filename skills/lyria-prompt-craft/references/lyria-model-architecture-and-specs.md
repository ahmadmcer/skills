# Lyria 3.5 Model Architecture & Technical Specifications

> _"Lyria 3.5 represents a paradigm shift in generative music: transitioning from short, repetitive audio loops into coherent, multi-minute compositions with structured verses, dynamic harmonic progressions, and realistic vocal articulation."_

---

## 1. Architectural Overview

Developed by **Google DeepMind**, the **Lyria 3.5** generative music family builds upon years of research in audio modeling (WaveNet, AudioPaLM, MusicLM).

```text
┌─────────────────────────────────────────────────────────────────┐
│                     LYRIA 3.5 GENERATION PIPELINE               │
├─────────────────────────────────────────────────────────────────┤
│ 1. Text / Multimodal Prompt     → Semantic conditioning         │
│ 2. Internal Composition Planner → High-level musical structure  │
│ 3. Neural Audio Codec Decoder   → 44.1 kHz Stereo latent space  │
│ 4. SynthID Watermark Injection  → Imperceptible provenance track│
│ 5. High-Fidelity Waveform Output→ Production-ready master audio │
└─────────────────────────────────────────────────────────────────┘
```

### Key Technical Milestones

- **Audio Fidelity**: High-resolution **44.1 kHz stereo output** with wide spatial separation and transparent dynamic range.
- **Structural Planning**: Unlike models that generate audio autoregressively token-by-token without macro-awareness, Lyria 3.5 incorporates an internal arrangement planning pass. It allocates energy, themes, and harmonic changes across the duration specified in the prompt.
- **Vocal Articulation & Prosody**: Capable of pronouncing complex lyrics with natural vibrato, breath control, and regional vowel formant shaping across multiple languages.
- **SynthID Watermarking**: Every audio file generated by Lyria 3.5 contains an imperceptible, tamper-resistant digital watermark embedded directly into the waveform spectrum, allowing Google to verify AI provenance without affecting listening fidelity.

## 3. Gemini API Integration Guide

Developers interact with the Lyria model family via the **Gemini API** using the Google GenAI SDK (`google-genai`).

### Full-Length Song Generation (`lyria-3.5`)

```python
from google import genai
from google.genai import types

client = genai.Client()

prompt_text = """
Genre: 1980s Dark Synthwave
Mood: Nocturnal, melancholic, building to an energetic climax
Instrumentation: Roland Juno-106 bassline, LinnDrum gated snare, vintage analog brass synths
Tempo: 115 BPM, 4/4 driving rhythm
Vocals: Baritone male vocal with subtle chorus effect

[0:00 - 0:20] Intro: Atmospheric arpeggiated synth pads with distant thunder.
[0:20 - 0:50] Verse 1: Driving bassline enters with close-mic vocal.
[0:50 - 1:20] Chorus: Exploding gated snare, soaring brass leads, and vocal harmonies.
[1:20 - 1:40] Outro: Bassline fades into solitary pulsing synth arpeggio.

Lyrics:
[Verse 1]
Neon reflections on the wet asphalt
Chasing the ghosts of another fault
The clock is ticking on a broken dream
Nothing is ever what it used to seem

[Chorus]
We ride the wire through the endless night
Searching for embers of an ancient light
Before the shadows take it all away
We find our freedom where the engines play
"""

response = client.models.generate_content(
    model="lyria-3.5",
    contents=prompt_text,
    config=types.GenerateContentConfig(
        temperature=0.75,
    ),
)

# Extract lyrics transcription, metadata, and audio bytes
for part in response.parts:
    if part.text:
        print("Model Metadata / Transcription:\n", part.text)
    elif part.inline_data:
        audio_bytes = part.inline_data.data
        with open("synthwave_track.wav", "wb") as f:
            f.write(audio_bytes)
        print("[PASS] Audio saved to synthwave_track.wav")
```

## 4. Hyperparameter Guidance

- **CFG Scale (Classifier-Free Guidance)**:
  - **Recommended: `6.0 – 7.5`**.
  - Setting CFG too high ($> 9.0$) forces the model into unnatural frequency clipping, harsh sibilance, and synthetic metallic artifacts.
  - Setting CFG too low ($< 4.0$) results in unguided, wandering harmonic structures that ignore user constraints.
- **Temperature**:
  - **Recommended: `0.7 – 0.85`**.
  - Lower temperatures ($0.5$) produce tighter, more predictable genre conventions.
  - Higher temperatures ($0.9$) introduce eclectic cross-genre fusions and unexpected melodic shifts.
- **Multimodal Audio Conditioning**:
  - Lyria 3.5 accepts images and video frames alongside text prompts, analyzing visual color palettes, tempo, and scene dynamics to steer harmonic mood.
